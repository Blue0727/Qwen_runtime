# 性能基准与原始样本

数据来自 2026-10-15 至 2026-10-17 的开发机实际运行。本次仓库整理没有重新运行推理或新增测量。

## 条件与定义

- Intel Core Ultra 7 255HX，Windows x64，MSVC 19.51，CMake 4.2.3，Release。
- Qwen2.5-0.5B Base，batch size 1，当前入口 KV 容量 512。
- 输入 `The capital of France is`，IDs 为 `[785,6722,315,9625,374]`，共 5 个 token。
- 每组加载一次模型、预热一次、测量三次；生成上限 16，以下均生成 16 个 token、实际执行 15 次 Decode forward。
- Prefill 计输入 token 的 forward 总时间，包含最后一个位置的词表输出，不包含第一个 token 的 greedy 选择。
- Decode 计 forward 累计时间 / 实际调用数，不含 greedy 扫描、分词、解码、加载、量化、进程启动或 HTTP。
- `tok/s = 1000 / decode_ms_per_forward`，属于 forward 吞吐，不是用户端完整生成吞吐。三次样本取中位数。

不同组的加速比不能相乘。三次短样本不能可靠估计尾延迟；电源 / 温度 / 后台负载未形成完整记录，结论限定在给定样本。

## FP32 SIMD 开关

同份代码切换 `QWEN_ENABLE_AVX2=OFF / ON`。ON 使用八通道 FP32 SIMD，并为整个 `operators.cpp` 启用 `/arch:AVX2`；未显式使用 FMA intrinsic 或 `/fp:fast`。

| AVX2 | 线程数 | Prefill 中位数 (ms) | Decode 中位数 (ms/token) |
|---|---:|---:|---:|
| OFF | 1 | 956.897 | 250.725 |
| ON | 1 | 384.466 | 94.892 |
| OFF | 16 | 200.046 | 50.204 |
| ON | 16 | 194.703 | 49.130 |

单线程 Decode 约加速 2.64×；16 线程约 1.02×，小幅差异未确认稳定性。开关改变整个算子源文件的编译目标，不能将全部差异只归因于一个点积函数。

## FP32 与 Q4 模型对照

固定 AVX2=ON、16 线程。Q4 量化每层七个投影，Norm、bias、Embedding 和共享输出层仍为 FP32。Q4 无手写 SIMD，普通 C++ 循环是否被编译器向量化未独立确认。

| 模式 | Prefill 中位数 (ms) | Decode 中位数 (ms/token) | Decode forward (token/s) |
|---|---:|---:|---:|
| FP32 | 218.180 | 50.508 | 19.799 |
| Q4 | 70.496 | 23.623 | 42.331 |

Prefill 加速 `218.180 / 70.496 = 3.095×`；Decode 加速 `50.508 / 23.623 = 2.138×`。Decode 单步耗时减少约 53.23%，不等于整个应用耗时减少相同比例。

## 文本结果与验证边界

短输入两条路径均成功返回并解码 16 个 token；首个 token 均为 ` Paris`，后续存在差异。FP32 IDs：

```json
[12095,13,1084,374,279,7772,3283,304,4505,323,279,2086,7772,304,279,1879]
```

Q4 IDs：

```json
[12095,13,1084,374,279,10723,315,279,8585,3033,323,279,3146,594,4948,323]
```

另一个输入使用 `data/story.txt` / `story_ids.json`，共 75 个 token，FP32 / Q4 均生成 128 个 token。Q4 后段反复出现 `Oh, nothing at all?`，FP32 本次没有相同的连续重复。两组均在达到上限时结束，文本可能停在句中。此组没有完整时间日志，不报告更长输入的加速。

量化可能改变 token 排名和后续上下文，但重复成因尚未定位。[Q4 内核检查](validation.md)不能替代全模型数值对齐或文本质量评估。目前没有独立参考框架的全模型误差、困惑度或标准任务分数，不能宣称量化无损。

本地网页已有功能运行反馈，没有单独 HTTP 性能数据；页面整段返回，完整响应时间不是 TTFT。
